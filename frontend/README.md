# Frontend

Aplicación React con Vite y TypeScript.

## Requisitos

- Node.js 20.19+ o 22.12+ (con npm)

## Ejecución

```bash
cp .env.example .env
npm install
npm run dev
```

La aplicación está disponible en `http://localhost:5173`.

Las decisiones técnicas están en el [README principal](../README.md).
